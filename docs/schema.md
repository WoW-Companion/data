# Dataset schema

Generated by `go run ./cmd/wowc-data schema` from the row types in `internal/schema/registry.go`; do not edit by hand. A test fails when this file differs from the command's output.

Each table is one Parquet file, `<table>.parquet`, in a dataset directory. `Null` is `yes` when the column is optional in the file. A source of `none` means the column exists for the schema but no allowed source fills it. Coverage per column on a built dataset: `go run ./cmd/wowc-data coverage <dataset dir>`. How each source was chosen and what it may carry: `sources.md`.

## items

One row per item the client lists, sorted by id. Source: wago.tools client table ItemSparse, Item, RandPropPoints, ItemArmorTotal, ItemArmorQuality, ItemArmorShield, ArmorLocation, ItemDamage*. File: `items.parquet`.

| Column | Type | Null | Source | Meaning |
| --- | --- | --- | --- | --- |
| `id` | `int32` | no | table | Item id. |
| `name` | `string` | no | table | Item name (ItemSparse Display_lang). |
| `item_level` | `int16` | no | table | Item level. |
| `required_level` | `int16` | no | table | Character level needed to equip or use it. |
| `quality` | `int8` | no | table | Quality id (0 poor, 1 common, 2 uncommon, 3 rare, 4 epic, 5 legendary). |
| `class_id` | `int8` | no | Item.ClassID | Item class id (2 weapon, 4 armor). |
| `subclass_id` | `int8` | no | Item.SubclassID | Item subclass id within the class. |
| `slot` | `int8` | no | table | Inventory type id (0 means not equippable). |
| `allowable_class_mask` | `int32` | no | table | Bit mask of classes that may use it; -1 means all. |
| `bonding` | `int8` | no | table | Bonding id (0 none, 1 on pickup, 2 on equip, 3 on use). |
| `stat_types` | `list<int16>` | no | table | Stat type ids the item lists, in slot order; empty when none (see stat_types). |
| `stats_status` | `string` | no | derived | known when stats are listed, unknown when a stat-bearing piece lists none, none otherwise. |
| `stats` | `list<struct{type int16, value int32?}>` | no | table | One {type, value} per listed stat. value is StatPercentEditor/10000 of the level budget (RandPropPoints by item level, quality and slot), rounded; null for a poor or common item, a zero share or a level with no budget row. |
| `armor` | `int32` | yes | table | Computed: ItemArmorTotal for the level and material x ItemArmorQuality x ArmorLocation for the slot (ItemArmorShield for shields), rounded. Null for non-armor, jewellery, relics and a zero result. |
| `dmg_min` | `int32` | yes | table | Computed: the level's ItemDamage* damage per second x ItemDelay, spread by DmgVariance, rounded; null for non-weapons and items with no delay. |
| `dmg_max` | `int32` | yes | table | Computed as dmg_min, upper end of the range (avg x (1 + DmgVariance/2)). |
| `speed_ms` | `int32` | yes | table | Weapon speed in milliseconds (ItemDelay); null for non-weapons or a zero delay. |
| `sell_price` | `int32` | yes | ItemSparse SellPrice | Vendor sell price in copper; null when the client stores zero. |
| `buy_price` | `int32` | yes | ItemSparse BuyPrice | Vendor buy price in copper; null when the client stores zero. |

| Column | Type | Null | Source | Meaning |

## talent_builds

Rows with source "curated (unverified)" are the project's old invented bands, kept only for specs whose Icy Veins WoW Forever leveling guide could not be read; rows read from the guide carry exact levels, one point per row (source_url and fetched_at filled). Source: curated YAML (curated/talents) validated against talent_nodes. File: `talent_builds.parquet`.

| Column | Type | Null | Source | Meaning |
| --- | --- | --- | --- | --- |
| `class` | `string` | no | table | Class name. |
| `spec` | `string` | no | table | Specialisation name. |
| `band` | `string` | no | table | Level band the step belongs to, low-high. |
| `order` | `int16` | no | table | Step number within the spec, from 1, across all bands. |
| `node_id` | `int32` | no | table | talent_nodes.node_id to spend points in. |
| `points` | `int16` | no | table | Ranks to add at this step. |
| `rationale` | `string` | no | table | Short reason for the band's choices. |
| `source` | `string` | no | table | "curated (unverified)" for the old bands, or "icy-veins.com WoW Forever leveling guides" for a row read from a guide. |
| `level` | `int16` | yes | table | Character level at which the point is spent; null on an unverified row. |
| `talent_name` | `string` | yes | table | Name of the talent the point goes into; null on an unverified row. |
| `rank_after` | `int16` | yes | table | Rank of the talent after the point; null on an unverified row. |
| `source_url` | `string` | yes | table | Guide page the row was read from; null on an unverified row. |

## class_spells

One row per class ability rank on a class skill line (Arms, Fury, Holy ...), once per class, skill line and spell. Filter on class_id and level for what a level unlocks. Talents, professions, pets and racials are not listed. Source: wago.tools client table SkillLine, SkillLineAbility, SkillRaceClassInfo, ChrClasses, SpellName, Spell, SpellLevels. File: `class_spells.parquet`.

| Column | Type | Null | Source | Meaning |
| --- | --- | --- | --- | --- |
| `class_id` | `int32` | no | SkillRaceClassInfo, SkillLineAbility | Class id (ChrClasses.ID) of the skill line; an ability ClassMask, when set, narrows it. |
| `spell_id` | `int32` | no | SkillLineAbility | Spell id of the ability rank. |
| `name` | `string` | no | SpellName | Spell name. |
| `rank` | `int16` | yes | Spell NameSubtext | Rank number when the spell's subtext reads "Rank N"; null otherwise. |
| `subtext` | `string` | yes | Spell NameSubtext | The spell's subtext (for example "Rank 2"); null when empty. |
| `level` | `int16` | no | SpellLevels | Level the spell becomes learnable: SpellLevel of the difficulty-0 row, BaseLevel when that is zero. Abilities with neither are not listed. |
| `skill_line_id` | `int32` | no | SkillLineAbility | Class skill line id. |
| `skill_line_name` | `string` | no | SkillLine | Class skill line name (a specialisation tree, for example Arms). |
| `superseded_spell_id` | `int32` | yes | SkillLineAbility SupercedesSpell | The previous rank this one replaces; null for a first rank. It may name a spell with no row here when that spell has no level. |
| `trained` | `bool` | yes | none | Always null: the client tables do not say whether a trainer teaches a spell or it is learned automatically. |

## quests_observed

One row per quest players observed, kept when Everloot lists it as settled or at least two distinct installs reported its title, sorted by quest id. Includes Forever's own quests (ids from 90000) that the client tables lack. A field is null unless the quest is settled or at least two installs reported that value. Join quests.id or loot_sources (source_kind quest reward) on quest_id. Source: Everloot observed quests (CC BY-SA 4.0). Data from Everloot (https://everloot.app), CC BY-SA 4.0.. File: `quests_observed.parquet`.

| Column | Type | Null | Source | Meaning |
| --- | --- | --- | --- | --- |
| `quest_id` | `int32` | no | Everloot | Quest id. |
| `title` | `string` | no | Everloot | Quest title as players saw it (the most reported spelling). |
| `level` | `int16` | yes | Everloot | Quest level; null when unsettled and fewer than two installs agree. |
